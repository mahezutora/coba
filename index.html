Pengaturan Google Apps Script URL

Masukkan URL Web App dari Google Apps Script untuk menghubungkan formulir ke spreadsheet REKAP USULAN.

💡 Tips jika muncul "Failed to fetch":
  • Pastikan saat Deploy, opsi Who has access (Yang memiliki akses) disetel ke Anyone (Siapa saja).
  • URL harus berakhiran /exec (bukan /edit atau link spreadsheet).
  • Pastikan otorisasi akun Google (Review permissions) sudah di-izinkan (Allow).

⚡ Konfigurasi Supabase Database (Opsional)

Jika sudah membuat proyek Supabase, masukkan Project URL & Anon Key agar data otomatis tersinkronisasi.
